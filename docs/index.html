  1. 01

    Both sides lock GEN

    The seller posts an offer with a bond equal to the price. A buyer fills it by locking the price. One trade, one escrow — no shared pool.

  2. 02

    Validators confirm the TGE

    Anyone proposes the token address. Validators must find it on the project's committed official domain and in the chain explorer with the same ticker.

  3. 03

    Open challenge window

    Anyone can show a different address that passes the same check. If one exists, nobody can say which token is real, so every trade is refunded.

  4. 04

    Delivery is read on-chain

    Seller sends the tokens from the committed wallet to the buyer's wallet and submits the tx. Delivered → seller paid. Late → buyer gets price + bond.
